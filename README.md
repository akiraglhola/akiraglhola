## Featured projects

### 🏠 [Madrid House Price Prediction](https://github.com/akiraglhola/streamlit-house-price-prediction)
End-to-end ML pipeline for predicting housing prices in Madrid (sale & rental).  
Scraping → cleaning → clustering → two parallel models optimized with Optuna → deployed Streamlit app with choropleth maps.  
`Python` `Scikit-learn` `Optuna` `Streamlit` `Plotly`

---

### 🌐 [Network Anomaly Detection with PySpark](https://github.com/akiraglhola/network-anomaly-pyspark)
Distributed pipeline processing 500K+ synthetic NetFlow records to detect port scans, DDoS attacks, and data exfiltration.  
Feature engineering (traffic ratios, temporal features, IP classification) → rule-based detection → Parquet export partitioned by protocol.  
`PySpark 3.5` `Python 3.11` `pandas` `Faker` `Parquet`
